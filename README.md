# DownloadKit

A Swift package for reliable, resumable, background-capable file downloads on iOS and macOS.

> **Status:** early development. The design is in [`docs/architecture.html`](docs/architecture.html); the API is not implemented yet.

## Requirements

- iOS 16+ / macOS 13+
- Swift 6 toolchain (Xcode 16+)

## Installation

```swift
dependencies: [
    .package(url: "https://github.com/elissonrusiel/DownloadKit.git", from: "0.1.0"),
]
```
